## 🛠️ Development Environment

To run the code in this repository, you will need:

1.  **Hardware**: 
    *   Raspberry Pi Pico (or Pico W for Wi-Fi modules).
    *   USB-to-Micro-USB cable.
2.  **Software**:
    *   [Visual Studio Code](https://code.visualstudio.com/).
    *   [MicroPico Extension](https://marketplace.visualstudio.com/items?itemName=paulober.pico-w-go) for VS Code (highly recommended).
3.  **Firmware**:
    *   Pico flashed with the latest [MicroPython UF2](https://micropython.org/download/rp2-pico/).

### Quick Setup with MicroPico
1.  Open this folder in VS Code.
2.  Connect your Pico to your computer.
3.  Ensure the **MicroPico** extension is active (check the status bar for "Pico Connected").
4.  Use the `Ctrl+Shift+P` -> `MicroPico: Run Current File` to execute your scripts.
